# Juan Martinez — Portfolio

Public portfolio at https://josejuanmartinez.github.io/.

Static HTML, CSS and JavaScript. Game previews are optimized, muted MP4 loops with downloadable GIF versions. Source recordings stay local.

## Update

Edit `repos.json` (public repositories only), then run `python build.py` to refresh the page. Edit `style.css` and `app.js` directly. Media lives in `assets/`.

GitHub Pages serves the root directory of the `main` branch. Push changes to publish.

## Studio showcase

The `#studio` section covers the closed-source games built at Agonia, starting with
**Possum Archaeologists**. The repositories are private, so the section deliberately links
nowhere — the art and the reels are the whole disclosure, and the screenshots are captures of
the running builds.

Media is derived from that package's `marketing/` rows (`store/` is itself generated by the
package's `marketing` script). With `$M` pointing at `packages/game-possumarch/marketing`:

```sh
magick $M/store/banner_portrait_1080x1920.png -resize 640x1138 -strip -quality 82   assets/possumarch-key.webp
magick $M/store/screenshot_portrait_2.png -resize 405x720 -strip -quality 80   assets/possumarch-board.webp
magick $M/store/screenshot_portrait_6.png -resize 405x720 -strip -quality 80   assets/possumarch-trench.webp
magick $M/store/screenshot_portrait_3.png -resize 405x720 -strip -quality 80   assets/possumarch-win.webp

# 1200x675 landscape key art. Used by the GitHub profile README, not by this page.
magick $M/store/banner_1920x1080.png -resize 1200x675 -strip -quality 84 -alpha off   assets/possumarch-banner.jpg

# The gallery reel is a REAL 6s gameplay capture, never the generated store trailer.
ffmpeg -y -ss 5 -t 6 -i $M/capture/raw-portrait.mp4 -vf "scale=540:960:flags=lanczos"   -c:v libx264 -crf 29 -preset slow -profile:v high -pix_fmt yuv420p -movflags +faststart   -an assets/possum_archaeologists.mp4
ffmpeg -y -ss 6.5 -i $M/capture/raw-portrait.mp4 -frames:v 1   -vf "scale=540:960:flags=lanczos" -q:v 4 assets/possum_archaeologists.jpg
ffmpeg -y -ss 5 -t 5 -i $M/capture/raw-portrait.mp4 -vf   "fps=12,scale=360:640:flags=lanczos,split[a][b];[a]palettegen=max_colors=128[p];[b][p]paletteuse=dither=bayer:bayer_scale=3"   -loop 0 assets/possum_archaeologists.gif
```

`assets/possumarch-banner.jpg` is hotlinked by `josejuanmartinez/josejuanmartinez`'s profile
README over `https://josejuanmartinez.github.io/`. Renaming or removing it breaks the image
on the GitHub profile.

### Glowdoku and Catnap

The section also carries **Glowdoku** and **Catnap**, built the same way at Agonia and just as
private: no links, only captures. Each is one `showcase(...)` call in `build.py`, with its
copy taken from the package's `MARKETING.md` (and, for Catnap, `COMBAT.md` and `src/data.ts`,
because its marketing copy predates the current roster). The gzip figures come from
`bun tools/size-check.ts packages/<pkg>` (entry chunk, 2026-09-24).

Everything is captured from the Agonia dev hub (`bun tools/hub.ts`, http://localhost:8100),
run from the Agonia repo root with `INIT="window.confirm=()=>false;"` so a dev-channel ad
cannot block headless Chrome. `$T` is any scratch directory outside both repos.

```sh
# Glowdoku: the package's own screenshot script, pointed at a scratch dir (stills 1, 3, 4).
bash packages/game-glowdoku/marketing/shots.sh $T/glow portrait
G=packages/game-glowdoku/marketing
magick $G/raw/banner_portrait.png -resize 640x960 -strip -quality 82   assets/glowdoku-key.webp   # generated key art (from a capture)
magick $T/glow/screenshot_portrait_1.png -resize 405x720 -strip -quality 80   assets/glowdoku-beams.webp
magick $T/glow/screenshot_portrait_3.png -resize 405x720 -strip -quality 80   assets/glowdoku-daily.webp
magick $T/glow/screenshot_portrait_4.png -resize 405x720 -strip -quality 80   assets/glowdoku-win.webp

# Catnap has no marketing/ folder, so the key art is a capture of its title screen.
U=http://localhost:8100/game-catnap/
bun tools/shot.ts $U $T/cat-menu.png 405 720 "window.catnap.home(0)" 6000 2500
bun tools/shot.ts $U $T/cat-home.png 405 720 "0" 6000 500
ORCHARD='(async()=>{const c=window.catnap;c.play(6);await new Promise(r=>setTimeout(r,5000));c.money(9000);[[5,8.5,6.5],[3,7.5,10],[4,4.5,14.5],[1,10.5,15.5],[0,4.5,20],[2,9.5,20],[7,1,9.5]].forEach(p=>c.place(p[0],p[1],p[2]));for(let i=0;i<7;i++)c.tier(i,i%3+1);c.round(3);})()'
bun tools/shot.ts $U $T/cat-orchard.png 405 720 "$ORCHARD" 6000 10000
PANEL='(async()=>{const c=window.catnap;c.play(6);await new Promise(r=>setTimeout(r,5000));c.money(9000);[[5,8.5,6.5],[3,7.5,10],[4,4.5,14.5],[1,10.5,15.5],[0,4.5,20],[2,9.5,20]].forEach(p=>c.place(p[0],p[1],p[2]));c.tier(0,3);c.round(2);await new Promise(r=>setTimeout(r,6000));c.select(0);})()'
bun tools/shot.ts $U $T/cat-panel.png 405 720 "$PANEL" 6000 1500
magick $T/cat-menu.png    -resize 640x1138 -strip -quality 82   assets/catnap-key.webp
magick $T/cat-orchard.png -resize 405x720 -strip -quality 80   assets/catnap-orchard.webp
magick $T/cat-panel.png   -resize 405x720 -strip -quality 80   assets/catnap-upgrade.webp
magick $T/cat-home.png    -resize 405x720 -strip -quality 80   assets/catnap-yard.webp

# Gallery reels: REAL headless recordings (tools/record.ts), one at a time — two in
# parallel starve SwiftShader down to ~2fps. Recording starts before the js runs.
bun tools/record.ts $U $T/cat-reel.mp4 540 960 "$ORCHARD" 6000 20000        # DSF=1
PRE=$(cat $G/stage.js)
bun tools/record.ts http://localhost:8100/game-glowdoku/ $T/glow-reel.mp4 540 960 \
  "$PRE; (async()=>{__m.fresh(2,7); const w=ms=>new Promise(r=>setTimeout(r,ms)); await w(1500); for(let k=0;k<8;k++){__m.put(__m.best(1)); await w(1400);} })()" 5000 15000   # DSF=1
# Then, per game ($IN/$SS/$OUT = cat-reel/10/catnap and glow-reel/1.5/glowdoku):
ffmpeg -y -ss $SS -t 6 -i $T/$IN.mp4 -vf "scale=540:960:flags=lanczos"   -c:v libx264 -crf 29 -preset slow -profile:v high -pix_fmt yuv420p -movflags +faststart   -an assets/$OUT.mp4
ffmpeg -y -ss $POSTER -i $T/$IN.mp4 -frames:v 1 -vf "scale=540:960:flags=lanczos" -q:v 4 assets/$OUT.jpg   # POSTER = SS + 1.5 (11.5 / 3)
ffmpeg -y -ss $SS -t 4 -i $T/$IN.mp4 -vf   "fps=10,scale=270:480:flags=lanczos,split[a][b];[a]palettegen=max_colors=64:stats_mode=diff[p];[b][p]paletteuse=dither=bayer:bayer_scale=4:diff_mode=rectangle"   -loop 0 assets/$OUT.gif
```

The GIFs are smaller than possumarch's recipe (4s, 10fps, 270x480, 64 colours): at 5s/12fps/360x640
these busier boards came out at 3.5-5.1MB. The hero's "game reels" count is `len(games)`.

## Project diagrams

`project-notes.json` records summaries, source links, and individual visual explanations based on each repository's README (and root files for sparse documentation). These diagrams describe concepts and workflows, not benchmark results.

Run `python render_diagrams.py` to create the 240 x 120 pixel PNG figures in `assets/figures/`, then `python build.py` to update the page. Diagram rendering uses Pillow. The site serves only compact diagrams and real gameplay media; earlier decorative illustrations are no longer referenced.

Each project has a bespoke composition: matrices for LoRA, route grids for pathfinding, token spans for NLP, interaction loops for RL, and domain-specific views for other projects. Any sample points or attributions are conceptual examples, not measured results.
