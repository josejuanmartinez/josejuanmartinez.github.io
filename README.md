# Juan Martinez — Portfolio

Public portfolio at https://josejuanmartinez.github.io/.

Static HTML, CSS and JavaScript. Game previews are optimized, muted MP4 loops with downloadable GIF versions. Source recordings stay local.

## Update

Edit `repos.json` (public repositories only), then run `python build.py` to refresh the page. Edit `style.css` and `app.js` directly. Media lives in `assets/`.

GitHub Pages serves the root directory of the `main` branch. Push changes to publish.

## Studio showcase

The `#studio` section covers **Possum Archaeologists**, the closed-source game built at
Agonia. Its repository is private, so the section deliberately links nowhere — the art and
the reel are the whole disclosure, and every image is a capture of the running build.

Media is derived from that package's `marketing/` rows (`store/` is itself generated by the
package's `marketing` script). With `$M` pointing at `packages/game-possumarch/marketing`:

```sh
magick $M/store/banner_portrait_1080x1920.png -resize 640x1138 -strip -quality 82   assets/possumarch-key.webp
magick $M/store/screenshot_portrait_2.png -resize 405x720 -strip -quality 80   assets/possumarch-board.webp
magick $M/store/screenshot_portrait_6.png -resize 405x720 -strip -quality 80   assets/possumarch-trench.webp
magick $M/store/screenshot_portrait_3.png -resize 405x720 -strip -quality 80   assets/possumarch-win.webp

# 1200x675 landscape key art. Used by the GitHub profile README, not by this page.
magick $M/store/banner_1920x1080.png -resize 1200x675 -strip -quality 84 -alpha off   assets/possumarch-banner.jpg

# The gallery reel is a REAL 6s gameplay capture, never the generated store trailer.
ffmpeg -y -ss 5 -t 6 -i $M/capture/raw-portrait.mp4 -vf "scale=540:960:flags=lanczos"   -c:v libx264 -crf 29 -preset slow -profile:v high -pix_fmt yuv420p -movflags +faststart   -an assets/possum_archaeologists.mp4
ffmpeg -y -ss 6.5 -i $M/capture/raw-portrait.mp4 -frames:v 1   -vf "scale=540:960:flags=lanczos" -q:v 4 assets/possum_archaeologists.jpg
ffmpeg -y -ss 5 -t 5 -i $M/capture/raw-portrait.mp4 -vf   "fps=12,scale=360:640:flags=lanczos,split[a][b];[a]palettegen=max_colors=128[p];[b][p]paletteuse=dither=bayer:bayer_scale=3"   -loop 0 assets/possum_archaeologists.gif
```

`assets/possumarch-banner.jpg` is hotlinked by `josejuanmartinez/josejuanmartinez`'s profile
README over `https://josejuanmartinez.github.io/`. Renaming or removing it breaks the image
on the GitHub profile.

## Project diagrams

`project-notes.json` records summaries, source links, and individual visual explanations based on each repository's README (and root files for sparse documentation). These diagrams describe concepts and workflows, not benchmark results.

Run `python render_diagrams.py` to create the 240 x 120 pixel PNG figures in `assets/figures/`, then `python build.py` to update the page. Diagram rendering uses Pillow. The site serves only compact diagrams and real gameplay media; earlier decorative illustrations are no longer referenced.

Each project has a bespoke composition: matrices for LoRA, route grids for pathfinding, token spans for NLP, interaction loops for RL, and domain-specific views for other projects. Any sample points or attributions are conceptual examples, not measured results.
